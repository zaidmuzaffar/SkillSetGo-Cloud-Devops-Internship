# Week 4: Capstone DevOps Project - Production-Grade Deployment

## Project Overview
This repository contains the final Capstone Project for the 4-week DevOps Internship at SkillSetGo. It consolidates concepts of Infrastructure as Code (IaC), Containerization, Orchestration, CI/CD Automation, and Security Best Practices.

## Completed Deliverables
- **Task 4.1: Architecture Layout** (`ARCHITECTURE.md`)
  - Defined end-to-end cloud and container orchestration workflow.
- **Task 4.2: Security & Logging** (`k8s-config/secret.yaml`)
  - Configured Kubernetes Secrets and ConfigMaps for secure environment variable management.
  - Validated pod stdout/stderr logs via `kubectl logs`.
- **Task 4.3 & 4.4: Automation & Capstone Delivery**
  - Integrated GitHub Actions for automated deployment checks.
  - Local cluster provisioning verified using Minikube and Terraform.
