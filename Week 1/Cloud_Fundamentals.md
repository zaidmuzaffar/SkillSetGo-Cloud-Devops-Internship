# Week 1: Cloud & AWS/Azure Fundamentals

## 1. Cloud Computing Service Models
- **IaaS (Infrastructure as a Service):** Provides raw compute, storage, and networking resources. (e.g., AWS EC2, Azure Virtual Machines)
- **PaaS (Platform as a Service):** Provides a managed runtime environment for deploying applications without managing underlying infrastructure. (e.g., AWS Elastic Beanstalk, Vercel, Render)
- **SaaS (Software as a Service):** Fully managed software applications delivered over the internet. (e.g., Google Workspace, Microsoft 365)

## 2. Core AWS & Cloud Services Overview
- **Compute (AWS EC2 / Azure VM):** Virtual servers running Linux/Windows for scalable workloads.
- **Storage (AWS S3 / Azure Blob Storage):** High-availability object storage for assets, backups, and static web hosting.
- **Networking (AWS VPC / Azure VNet):** Isolated virtual networks configured with public/private subnets and security group rules.
- **Identity & Access Management (AWS IAM):** Granular access control and policy management for cloud resources.

## 3. Architecture Consideration for Mini Project 1
For deploying our static application in Mini Project 1, a PaaS/Static Hosting architecture (like Vercel or Render) provides seamless continuous integration, SSL security, and global CDN delivery.
