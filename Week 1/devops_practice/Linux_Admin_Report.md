# Linux Administration Exercises - Week 1

## Objective
Practiced essential Linux system administration commands including directory management, file permissions, and process monitoring.

## Commands Executed
- Directory & File Management: `pwd`, `mkdir`, `echo`, `cat`, `ls -la`
- File Permissions: `chmod 444`, `chmod 644`
- System Monitoring: `uptime`, `ps aux`, `top`

## Key Learnings
1. Learned how file permissions (`rwx`) work in Unix environment.
2. Understood how to monitor live system resource consumption using `top` and `ps`.
